# Music Recommendation App

A Streamlit music recommendation system using content-based filtering with cosine similarity.

## Files
- app.py: Streamlit application
- requirements.txt: Python dependencies
- dataset_cleaned.csv: cleaned dataset used by the app

## Run locally
1. Install dependencies:
   pip install -r requirements.txt
2. Start app:
   streamlit run app.py

## Deploy on Streamlit Cloud
1. Push this folder to a GitHub repository.
2. In Streamlit Cloud, create a new app from that repository.
3. Set main file path to app.py.
